# ChatLima

ChatLima is a simple chatbot that lets students check their own academic results — branch, marks, and attendance — by asking questions in plain English, instead of searching through spreadsheets manually.

## Features
- Ask questions like "who is Sita" or "what are Ravi's marks"
- Handles empty input and unknown student names gracefully
- Handles missing data (e.g. blank marks) without crashing
- Logs every question and answer to `chatlima.log`
- Covered by automated tests (pytest)
